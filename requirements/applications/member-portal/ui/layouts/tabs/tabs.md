# Tabs

This document describes the expected user-facing behavior of this screen or component.

## Status

Working draft. Confirm the behavior and any role or policy rules with stakeholders before approval.

## UI-MEM-011-01 — Tabs: Screen structure

**Requirement:** The tabs screen presents the task with a clear identifying heading.

**Acceptance criteria:**
- The screen displays its main content with a clear heading.

**Previous screen-level ID:** `UI-MEM-011`

## UI-MEM-011-02 — Tabs: User actions

**Requirement:** The user can complete the actions available on this screen.

**Acceptance criteria:**
- The screen clearly offers the available actions: Home; Groups; Courses; Posts; Open profile menu; My profile; Sign out.

**Previous screen-level ID:** `UI-MEM-011`

## UI-MEM-011-03 — Tabs: Navigation

**Requirement:** The user can navigate to related screens from this screen.

**Acceptance criteria:**
- The user can navigate to the relevant area (/home; /groups; /courses; /posts; /me).

**Previous screen-level ID:** `UI-MEM-011`

## UI-MEM-011-04 — Tabs: Conditional UI states

**Requirement:** The tabs screen communicates loading, empty, error, and unavailable states when they apply.

**Acceptance criteria:**
- The screen provides a clear way to move to related screens.

**Previous screen-level ID:** `UI-MEM-011`
