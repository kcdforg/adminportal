# Group Form Dialog

This document describes the expected user-facing behavior of this screen or component.

## Status

Working draft. Confirm the behavior and any role or policy rules with stakeholders before approval.

## UI-ADM-016-01 — Group Form Dialog: Screen structure

**Requirement:** The group form dialog screen presents the task with a clear identifying heading.

**Acceptance criteria:**
- The screen displays its main content with a clear heading.

**Previous screen-level ID:** `UI-ADM-016`

## UI-ADM-016-02 — Group Form Dialog: Input controls

**Requirement:** The group form dialog screen provides clearly labeled controls appropriate to the task.

**Acceptance criteria:**
- The screen provides controls for the information needed to complete the task: group_name (input); display_name (input); description (textarea); category_id (select).

**Previous screen-level ID:** `UI-ADM-016`

## UI-ADM-016-03 — Group Form Dialog: User actions

**Requirement:** The user can complete the actions available on this screen.

**Acceptance criteria:**
- The screen clearly offers the available actions: Cancel.

**Previous screen-level ID:** `UI-ADM-016`

## UI-ADM-016-04 — Group Form Dialog: Conditional UI states

**Requirement:** The group form dialog screen communicates loading, empty, error, and unavailable states when they apply.

**Acceptance criteria:**
- The screen explains when data cannot be loaded or an action fails; indicates when an action is unavailable.

**Previous screen-level ID:** `UI-ADM-016`
