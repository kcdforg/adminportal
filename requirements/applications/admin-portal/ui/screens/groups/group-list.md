## UI-ADM-017-01 — Groups: Screen structure

**Requirement:** The groups screen presents the task with a clear identifying heading.

**Acceptance criteria:**
- The screen displays its main content with a clear heading (Groups; Group categories).

**Previous screen-level ID:** `UI-ADM-017`

## UI-ADM-017-02 — Groups: Input controls

**Requirement:** The groups screen provides clearly labeled controls appropriate to the task.

**Acceptance criteria:**
- The screen provides controls for the information needed to complete the task: Category name (input); Description (input); Edit category name (input); Edit category description (input).

**Previous screen-level ID:** `UI-ADM-017`

## UI-ADM-017-03 — Groups: User actions

**Requirement:** The user can complete the actions available on this screen.

**Acceptance criteria:**
- The screen clearly offers the available actions: Manage Categories; Create Group; Save; Cancel; Edit.

**Previous screen-level ID:** `UI-ADM-017`

## UI-ADM-017-04 — Groups: Conditional UI states

**Requirement:** The groups screen communicates loading, empty, error, and unavailable states when they apply.

**Acceptance criteria:**
- The screen shows progress while data is loading; explains when data cannot be loaded or an action fails; explains when there is no content to display; indicates when an action is unavailable; supports navigating between pages of results; provides a clear way to move to related screens.

**Previous screen-level ID:** `UI-ADM-017`
